iPhone Safari / Android Chrome Sound Improvements
- Speech starts directly from user tap (browser permission requirement).
- Japanese voice preferred, fallback to browser default if selected voice fails.
- Utterance kept in memory until playback ends for iOS compatibility.
- Errors reported in page status.
- No external audio hosting or API key needed.
LIMITATION: no code can guarantee sound on every device; silent mode, device volume, installed voices, browser policies and OS settings vary.
Real device audio testing has not been performed.
